# Data Science Job Risk: Case Study

Machine learning case study on the **Data Science salaries** dataset (2024 and 2025 editions). Written for the ML course (23ISR021), Kongu Engineering College.

## Contents

| File | What it is |
| --- | --- |
| `Case Study 23ISR021 ML.pdf` | Full case-study report |
| `DataScience_salaries_2024.csv` | Salary data, 2024 edition |
| `DataScience_salaries_2025.csv` | Salary data, 2025 edition |

## Dataset columns

`work_year`, `experience_level`, `employment_type`, `job_title`, `salary`, `salary_currency`, `salary_in_usd`, `employee_residence`, `remote_ratio`, `company_location`, `company_size`
